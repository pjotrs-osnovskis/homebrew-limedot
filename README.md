# LIMEDOT apps for Homebrew

The official Homebrew tap for LIMEDOT's Mac apps.

```bash
brew install --cask pjotrs-osnovskis/limedot/dockbar
```

| App | What it is | Website |
|---|---|---|
| DockBar | Widgets in the empty space beside the Dock: your next meeting, a focus timer, Mac health and a clock | https://limedot.io/dockbar/ |

Each cask installs the same signed and notarized download as the app's website: Developer ID of LIMEDOT SIA, Team ID `YH67YBD663`. The apps then keep themselves up to date through their built-in updater.
